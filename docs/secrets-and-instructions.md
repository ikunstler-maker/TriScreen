# Паролі, ключі й покрокові інструкції

Два обов'язкові правила для Claude і посібник для вас. Справжніх значень у документах і в чаті ніколи немає — лише назви записів і шляхи, де значення шукати.

## Як додати в новий проєкт
1. Скопіюйте файл у новий репозиторій як `docs/secrets-and-instructions.md`.
2. У `CLAUDE.md` вставте блок з розділу «Блок для CLAUDE.md» (в кінці).
3. Замініть `TriScreen` на назву проєкту.
4. Коли з'являться перші сервіси, попросіть Claude: «Склади посібник із паролів за розділом 3 docs/secrets-and-instructions.md».

## Частина 1. Паролі й ключі

### 1.1. Три правила
1. **Один менеджер паролів.** Усе лише в ньому: ні блокнота, ні файлу на робочому столі, ні нотаток у телефоні. Підійде будь-який із папками, кількома полями, нотатками, вкладеннями й двоетапним входом (наприклад, безкоштовний Bitwarden). Головний пароль менеджера — напам'ять і на папері вдома; це єдиний пароль поза менеджером.
2. **Паролі не пересилаються.** Ні в чат з Claude, ні собі на пошту, ні в месенджери; не фотографувати. Якщо Claude потрібен ключ — він відкриває захищену форму або просить вас самостійно вставити значення в панель сервісу.
3. **Claude називає запис точно за посібником проєкту.** Якщо назва інша — нагадайте про посібник; правильна та, що в посібнику.

### 1.2. Схема назв у менеджері
- **Папки:** `TriScreen · Акаунти`, `TriScreen · Сервер`, `TriScreen · Ключі шифрування`, по одній на кожен сервіс, `TriScreen · Інше`.
- **Назва запису:** `TriScreen · <Сервіс> · <що це>`. Розрізняйте середовища великими літерами: «ключ ОСНОВНОГО сайту», «ключ ТЕСТОВОГО сайту».
- **Поля** — так, як їх показує сервіс (англійською, як на екрані).
- **Нотатки кожного запису:**
  - Де знайти / створити знову: точний шлях;
  - Показується один раз? так / ні;
  - Інше: розбіжності, застереження.

### 1.3. Що зберігати
| Позначка | Значення |
|---|---|
| **Обов'язково** | Без вашої копії не відновити (показується один раз, ключі шифрування, пароль SSH-ключа, коди 2FA) |
| **Бажано** | Можна знову подивитися в панелі, але копія зручна |
| **Не обов'язково** | Публічні значення, перемикачі, адреси, те, що можна легко створити заново |

Найважливіше завжди: входи в акаунти й коди 2FA, SSH-ключ і його пароль, ключі шифрування даних (їх ніколи не міняють), секрети, що показуються лише раз.

### 1.4. Як Claude повідомляє про новий пароль чи ключ
Щоразу, коли вам треба щось зберегти, Claude дає готовий запис:
```
Папка: TriScreen · <Сервіс>
Назва запису: TriScreen · <Сервіс> · <що це>
Поля: <як на екрані сервісу>
Де знайти / створити знову: <екран → розділ → поле>
Показується один раз: так / ні
Зберігати: Обов'язково / Бажано / Не обов'язково
Знадобиться: <у якому наступному кроці/запиті>
```
- Значення ви копіюєте з сервісу прямо в менеджер; у чат — ніколи.
- Одноразові коди (реєстрація, підтвердження) не зберігаються і не вставляються в чат.
- Коли просить значення, Claude пише: «відкрийте запис **<назва>**, поле **<поле>**, вставте його в <екран → поле>».
- Ви відповідаєте лише «додала» / «вставила», без значення.

### 1.5. Що робити при розбіжностях
- Значення в двох місцях різні → **нічого не міняйте й не викидайте**, запишіть обидва в нотатку й скажіть Claude назву запису (без значення).
- Пароль невідомий → не вгадуйте й не скидайте без Claude; позначте «невідомий, як скинути: …».
- Не знаєте, куди віднести значення → назвіть Claude лише **назву**, не значення.

### 1.6. Розділи посібника проєкту (Claude складає його для кожного проєкту)
1. Три правила (як у 1.1).
2. Менеджер паролів.
3. Схема назв: міні-словник, папки, повний список записів таблицями `Назва | Поля | Де знайти | Нотатки | Зберігати?`.
4. «Зібрати все за один вечір»: нумеровані кроки, спершу акаунти, перевірка кожного входу; старий блокнот видаляється лише після повної перевірки.
5. «Що я проситиму найчастіше»: `Коли Claude пише… | Відкрийте запис | Поле`.
6. «Що зберігати не треба» з причиною для кожного пункту.

## Частина 2. Покрокові інструкції

### 2.1. Правила для Claude
- Ніколи «знайдіть розділ» чи «налаштуйте». Завжди точний шлях: **екран → розділ → поле → кнопка**.
- **Одна дія — один нумерований крок.** Підкроки — 11а, 11б.
- Точний текст для пошуку (Ctrl+F) і точний блок, який виділити.
- Що вставити — весь готовий блок цілком (тут код-блок дозволений).
- Після кожної важливої дії — **як перевірити**, що вийшло.
- Перед ризиковим кроком (видалення, заміна, скидання пароля) — попросити скриншот і пояснити, що буде, якщо помилитися.
- Якщо екран може відрізнятися — спершу скриншот, потім інструкція.
- Терміни англійською — як на екрані сервісу; незнайомі пояснити в міні-словнику на початку.
- Що робити, якщо щось пішло не так: «не міняйте нічого, напишіть мені номер кроку».

### 2.2. Зразок
```
Крок 3/5. Додати ключ у налаштування сайту
1. Відкрийте <панель> → застосунок <назва> → вкладка Environment Variables.
2. Натисніть Ctrl+F і введіть RESEND_API_KEY.
   – Якщо рядок є: натисніть олівець праворуч від нього.
   – Якщо немає: натисніть кнопку + Add.
3. У поле Value вставте значення із запису «TriScreen · Resend · ключ для листів сайту», поле API Key.
4. Натисніть Save.
Перевірка: у списку біля RESEND_API_KEY видно замочок, значення приховане.
Якщо щось виглядає інакше — нічого не міняйте, надішліть скриншот.
```

## Блок для CLAUDE.md
```
## Secrets & owner instructions
- Owner keeps all secrets in one password manager; never in chat, email, notes or screenshots. Details: `docs/secrets-and-instructions.md`.
- Record names follow `<Project> · <Service> · <what>` and the project's passwords guide; always name the exact record and field.
- Whenever the owner must save a secret: give the ready entry (folder, record name, fields, where to find/recreate, shown once?, keep level, needed in which step). One-time codes are never saved or pasted.
- Need a secret: secure credential form, or ask the owner to paste it into the service panel herself; owner replies only «додала».
- Mismatch or unknown value: change nothing, owner reports the record name only.
- Owner steps outside the repo: exact screen → section → field → button; one action per numbered step; exact Ctrl+F text; full block to paste; how to verify; screenshot before risky steps; "if it differs — stop and send the step number".
```
