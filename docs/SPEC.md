# TriScreen — специфікація

## Мета й обмеження
Безкоштовний вебсайт для самостійного психологічного скринінгу (стандартизовані опитувальники) і щоденного самоспостереження.
- Не замінює консультацію фахівця; результати — орієнтир.
- Без сервера: дані користувачів зберігаються лише в їхньому браузері.
- Хостинг: GitHub Pages з гілки `main`.
- Поточна мета (листопад 2026): **стабільність і порядок** — без нових функцій, доки не налагоджено процес і перевірки.

## Користувачі й ролі
- Відвідувач — проходить тести, веде щоденники, зберігає історію локально.
- Власниця — керує змістом і пріоритетами.

## Модель даних
localStorage у браузері відвідувача. Зміна ключів чи формату — лише з дозволу.

## Правила доступу
Публічний сайт, входу немає.

## Етапи
### Етап 1 — Процес і автоматичні перевірки (CI-1…CI-3)
Готово, коли:
- [ ] базові файли процесу в репозиторії (цей PR);
- [ ] кожен PR автоматично перевіряє HTML і биті посилання;
- [ ] биті посилання на сайті виправлені.

### Етап 2 — EntroLog: впорядкування джерела
Готово, коли:
- [ ] обрано й записано спосіб, як оновлювати EntroLog;
- [ ] EntroLog відкривається з головної сторінки.

## Ризики
- `index.html` дуже великий — ризик випадково зламати сторінку; пом'якшення: перевірки CI.
- Зміна формату збереження — втрата історії користувачів.
