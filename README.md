UPD: **TriScreen_app_260914-1**

Додано новий опитувальник.

Life Events Checklist for DSM-5 (LEC-5) by CETA — це важливий інструмент самодіагностики, який використовується для оцінки впливу різних стресових та травматичних життєвих подій. Згідно з наданим вами зображенням, опитувальник складається з 11 пунктів, де респондент відповідає "Ні" (0 балів), "Так, 1 раз" (1 бал) або "Так, більше одного разу" (2 бали).

Що було зроблено:
Створення вкладки LEC-5: Додано нову картку на головній сторінці (Вступ) та окрему секцію-вкладку для проходження опитування LEC-5.

Структура опитування: Опитування складатиметься з 11 тверджень, як зазначено у вашому документі (стихійні лиха, фізичне насильство, битви тощо), з трьома варіантами відповіді (0, 1 або 2 бали).

Логіка підрахунку: Алгоритм сумуватиме бали. Згідно з наданим зображенням (і загальною практикою для LEC), інтерпретація зазвичай базується на наявності досвіду. Ми можемо встановити базову інтерпретацію (наприклад, "Низький" для 0 балів, "Помірний" для 1-10 балів, "Високий" для 11-22 балів) або адаптувати її під ваші специфічні вимоги, якщо ви надасте детальну інструкцію. Я зроблю базовий підрахунок суми балів.

Інтеграція в результати: Тест LEC-5 буде інтегровано в сторінку результатів (Dashbord) і PDF-експорт нарівні з іншими тестами. У PDF буде виводитися таблиця з відповідями, як і для GAD-7, PCL-5, PHQ-9, DES-II.
